Task 22: Displaying Updated Global Variable Using Add and Subtract Functions

PHP Code Used

$number = 90;

function add() {
    global $number;
    $number = $number + 10;
    echo $number;
}

function sub() {
    global $number;
    $number = $number - 50;
    echo $number;
}

add();
sub();

Output

Initial global value

$number = 90

Calling add()

Inside add(): 90 + 10 = 100

Global $number after add(): 100

Calling sub()

Inside sub(): 100 - 50 = 50

Global $number after sub(): 50

The global keyword lets each function change the same $number variable. So sub() starts from 100 (the value left by add()), not from 90.
