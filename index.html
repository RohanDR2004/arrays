Task 16: Applying Comparison and Logical Operators on Variables with Type Verification

Part 1: Comparison Operators

Case 1: $a = "raj"; $b = "raj";

gettype($a): string   |   gettype($b): string

var_dump($a): string(3) "raj"
var_dump($b): string(3) "raj"
OperatorExpressionResult
Equal (==)$a == $bTRUE
Not Equal (!=)$a != $bFALSE
Identical (===)$a === $bTRUE
Not Identical (!==)$a !== $bFALSE
Greater Than (>)$a > $bFALSE
Less Than (<)$a < $bFALSE
Greater Than or Equal (>=)$a >= $bTRUE
Less Than or Equal (<=)$a <= $bTRUE

Both values are the same string, so == and === are both TRUE. Strings are compared alphabetically for > and <.

Case 2: $a = 90; $b = 34;

gettype($a): integer   |   gettype($b): integer

var_dump($a): int(90)
var_dump($b): int(34)
OperatorExpressionResult
Equal (==)$a == $bFALSE
Not Equal (!=)$a != $bTRUE
Identical (===)$a === $bFALSE
Not Identical (!==)$a !== $bTRUE
Greater Than (>)$a > $bTRUE
Less Than (<)$a < $bFALSE
Greater Than or Equal (>=)$a >= $bTRUE
Less Than or Equal (<=)$a <= $bFALSE

90 is greater than 34, so >, >=, != and !== are TRUE.

Difference between == and === : $a = 90; $b = "90";

gettype($a): integer   |   gettype($b): string

var_dump($a): int(90)
var_dump($b): string(2) "90"
OperatorExpressionResult
Equal (==)$a == $bTRUE
Identical (===)$a === $bFALSE
Not Equal (!=)$a != $bFALSE
Not Identical (!==)$a !== $bTRUE

== only checks the value (90 equals "90" → TRUE). === checks the value AND the datatype (integer is not string → FALSE).

Part 2: Logical Operators

var_dump($b): int(40)

Case 2: $a = -2; $b = 70;

gettype($a): integer   |   gettype($b): integer

var_dump($a): int(-2)
var_dump($b): int(70)
OperatorExpressionResult
AND (&&)($a > 0) && ($b > 0)FALSE
AND (&&)($a < $b) && ($b < 100)TRUE
OR (||)($a > 0) || ($b > 0)TRUE
OR (||)($a > 50) || ($b > 50)TRUE
NOT (!)!($a > 0)TRUE
NOT (!)!($b > 0)FALSE

&& is TRUE only when both conditions are TRUE. || is TRUE when at least one condition is TRUE. ! reverses the result.
